\begin{abstract}
      分布式数据库已成为现代互联网应用迈向分布式与云原生架构的重要基础设施。面对高并发和多样化业务需求，系统设计长期需要在数据一致性与执行性能之间进行权衡：单一强隔离级别能够提供严格的正确性保障，但往往带来较高的并发控制开销；单一弱隔离级别虽然吞吐量较高，却难以满足关键事务的严格一致性要求。

      针对上述问题，本文围绕混合隔离级别事务的统一语义建模与系统实现展开研究，设计并实现了一个基于分片（Sharding）架构、支持混合隔离级别的分布式键值数据库原型。本文提出了一种面向混合隔离级别场景的并发控制协议，使事务能够根据业务需求选择不同隔离级别，并支持跨分片事务的原子执行。

      为保证协议在混合场景下的正确性，本文使用 \TLAPlus 对系统操作语义进行形式化建模，并通过模型检查验证关键安全属性；随后构建了一个分布式数据库验证平台，实现了分布式事务调度、多版本并发控制（MVCC）存储引擎以及网络通信模块，用于模拟分布式环境下的事务处理流程。

      基准测试结果表明，本文设计的混合隔离级别机制能够正确执行混合事务逻辑；相较于统一采用强隔离级别的基线配置，该机制在本文测试的三类负载和两种部署方式下均提高了系统吞吐量。这些结果支持本文的基本判断：在事务语义可区分的场景中，按事务需求选择隔离级别可以减少一部分不必要的同步开销，并给出一种从语义约束到事务执行路径的实现方式。
\end{abstract}

\begin{abstract*}
      Distributed databases have become essential infrastructure for modern internet applications moving toward distributed and cloud-native architectures.

      Under high concurrency and diverse workloads, system design must continually balance data consistency against execution performance:
      a single strong isolation level provides strict correctness guarantees but often incurs substantial concurrency-control overhead,
      whereas a single weak isolation level may deliver higher throughput but cannot satisfy the stringent consistency requirements of critical transactions.

      To address this problem, this thesis studies unified semantic modeling and system implementation for transactions running under mixed isolation levels.
      We design and implement a prototype distributed key-value database based on a sharding architecture that supports mixed isolation levels, and propose a concurrency control protocol tailored to such scenarios.
      The protocol allows transactions to select different isolation levels according to application requirements while supporting atomic execution of cross-shard transactions.

      To ensure correctness in mixed-isolation settings, we model the system semantics using \TLAPlus and verify key safety properties through model checking.
      Based on the verified model, we further build a distributed database validation platform that implements distributed transaction scheduling, a multi-version concurrency control (MVCC) storage engine, and network communication modules for realistic simulation of distributed transaction processing.

      Benchmark results show that the proposed mechanism executes mixed transaction logic correctly and, compared with a baseline configuration that uniformly adopts a strong isolation level, improves system throughput under the workloads and deployment settings evaluated in this thesis while preserving the required semantic guarantees.
      These results suggest that selecting isolation levels according to transaction requirements can reduce part of the synchronization overhead and provide an implementation path from semantic constraints to transaction execution.
\end{abstract*}
