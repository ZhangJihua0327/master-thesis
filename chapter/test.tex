\chapter{基于分布式KV数据库原型的系统测试与验证}
本文基于前述原型系统，对不同隔离级别配置下的事务执行性能进行测试，以验证混合隔离级别机制相较于单一强隔离级别方案在吞吐量上的优势。本章首先介绍测试环境与评测方法，然后给出三个数据集在两种部署拓扑下的吞吐量结果，并据此分析不同隔离级别配置的性能差异。

\section{测试环境概述}
数据库原型系统基于 Golang 开发，并通过 Docker 容器模拟分布式数据库集群。测试均在本地环境中完成，容器的 CPU 与内存配额保持一致，以避免资源分配差异对结果造成额外干扰。集群由 Router、Shard 与 Config 三类节点组成，其中 Config 节点仅保留单节点部署，因为其主要承担元数据管理职责，对吞吐量影响较小。

本文重点考察两种部署拓扑：\textbf{single-az} 表示系统组件集中部署在单一逻辑域内，\textbf{pair-az} 表示系统组件分散在两个逻辑域内。这里沿用实验数据中的命名，以便与统计结果和生成图保持一致。两种拓扑使用相同的事务负载与资源限制，因而测试结果的差异主要反映部署分散程度对分布式事务协调开销的影响。

\section{测试负载与评价指标}
为了更全面地考察系统在不同业务模式下的表现，本文选取了 Courseware、SmallBank 和 TPCC 三个数据集。三个数据集分别覆盖课程管理、银行转账和订单处理等不同类型的事务访问模式，能够反映混合隔离级别在多种典型负载下的适用性。

测试中比较了三种隔离级别配置：\textbf{SER} 表示所有事务均采用可串行化隔离级别；\textbf{SI-SER} 表示事务在快照隔离与可串行化之间混合执行；\textbf{MIAED} 则表示在满足正确性约束的前提下，由混合隔离级别分配策略为事务选择更低成本的执行级别。评价指标采用平均吞吐量（transactions per second, tx/s），用于衡量系统在稳定运行阶段的整体处理能力。

从图~\ref{fig:throughput-single-az} 可以看出，在 single-az 拓扑下，SER 的平均吞吐量为 69.36 tx/s，SI-SER 提升到 74.51 tx/s，平均增幅约为 7.42\%。这说明即使只在 SI 和 SER 两个较强隔离级别之间进行混合调度，也已经能够缓解一部分由全局串行化带来的并发约束。相比之下，MIAED 的平均吞吐量达到 206.19 tx/s，相较于 SER 提升约 197.28\%，相较于 SI-SER 进一步提升约 176.74\%。在三个数据集上，这一趋势都十分稳定：Courseware 上 MIAED 相比 SER 提升约 197.94\%，SmallBank 上提升约 196.81\%，TPCC 上提升约 197.10\%。

在 pair-az 拓扑下，整体吞吐量显著下降，但不同隔离级别之间的相对关系保持不变。SER 的平均吞吐量为 7.13 tx/s，SI-SER 为 7.62 tx/s，平均增幅约为 6.85\%；MIAED 则达到 21.17 tx/s，相较于 SER 提升约 196.81\%，相较于 SI-SER 提升约 177.78\%。分数据集来看，MIAED 在 Courseware、SmallBank 和 TPCC 上相较于 SER 的提升分别为 195.40\%、194.87\% 和 200.18\%。这表明，尽管部署拓扑更加分散会放大分布式事务的协调成本，但混合隔离级别机制仍然能够持续带来接近 3 倍的吞吐量收益。

进一步比较两种拓扑可以发现，从 single-az 切换到 pair-az 后，三种策略的平均吞吐量均下降到原来的约 10\% 左右：SER 下降约 89.72\%，SI-SER 下降约 89.77\%，MIAED 下降约 89.73\%。这说明部署分散程度会显著拉长事务的提交路径，并放大跨节点协调与通信等待的开销。不过，更重要的是，不同策略之间的相对优势在两类拓扑中几乎保持一致。换言之，MIAED 带来的性能改善并非特定部署条件下的偶然现象，而是来源于其本身对事务隔离强度进行按需分配的机制优势。

综合三组数据可以得到两个结论。第一，单一 SER 虽然提供了最强的一致性保证，但其保守的并发控制会明显压制系统吞吐量；将部分事务放宽到 SI-SER 后，可以取得有限但稳定的性能提升。第二，基于更细粒度事务分类的 MIAED 能够在不破坏正确性前提下显著降低不必要的强同步开销，因此在三个数据集、两种拓扑下都取得了最优吞吐量结果。这表明，混合隔离级别并不是局部优化，而是一种能够在多类工作负载上稳定发挥作用的系统级优化手段。

\section{本章小结}
本章基于分布式 KV 数据库原型，对 Courseware、SmallBank 和 TPCC 三个数据集进行了吞吐量测试，并比较了 SER、SI-SER 与 MIAED 三种隔离级别配置在 single-az 与 pair-az 两种拓扑下的表现。实验结果表明，混合隔离级别配置能够在不同数据集上稳定提升系统吞吐量，其中 MIAED 在两类拓扑下均获得了最优结果。测试结果验证了本文所设计的混合隔离级别机制能够在保持事务正确性的同时，显著提升分布式事务处理性能。
